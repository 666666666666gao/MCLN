# PV-Ground＋G → expression-conditioned P2

用户最新主线取代此前整套MCLN模块移植方案。原版PV-Ground是论文baseline；
已验证PV-Ground＋G是当前强起点。旧MCLN/V99仅保留历史成绩、权重与问题证据。
旧模块移植完成工程预检，但不启动正式21轮训练。

## 本轮唯一结构变量

P2在最后层D/G读取上新增完整文本条件与候选相对位置读取。复用六源内容和
C的10/13维实际观测状态，保留所有原有D/G参数。候选先读取非padding文本，
再在六源记忆上联合使用内容、观测状态、候选尺度归一化坐标和真实相对距离。
读取结果通过零初始化输出层，作为同一实例残差加入原末层任务读取，之后
沿用相同norm、FFN和原生语义/几何头。只有一套部署排名。

本轮不加P3，不改TGS、文本骨干、Mask损失、G规则，不用V99教师或后处理。
P2输入框是前一层预测，坐标和尺寸沿用原生detach，不使用GT输入。

## 同起点、同预算

- 起点：作者epoch81核心严格加载后，覆盖已完成G的1072项终态delta；
  G终态SHA `0575dfae333dabdf288a470fc09d8967f9867d1853a5f61d9cfc3cbcf7964522`。
- 两臂：G继续适配控制；G＋P2。两臂均重新建立AdamW，明确不继承旧优化器。
- 复用既有物理场景划分：29778 fit行、6887模块留出行；单次fit消费、3723更新。
- seed2027，物理/有效batch8，core/backbone LR均1e-5，wd5e-4，clip0.1。
  P2亦使用同一LR；先实测容量，不迁入MCLN batch12配方。
- 完整原生loss＋既有G末层CE替换；其他目标和匹配保持原样。
- 两臂相同输入顺序、增强、loss与评估；固定终点，不按单项最佳拼接模型。
- 各自起点和终点评估6887行；两个终点均评估正式9508行，不以留出涨点筛选
  哪个模型才参加正式评估。正式验证是开发验证。

模块留出场景曾被作者预训练见过，不能冒充正式泛化。新方法披露G既有训练历史
及本轮额外预算。正结果要求同预算双阈值净增益，并检查相对G起点的能力保持。
ScanRefer开发目标保住59.0555%宽松定位优势、争取严格≥50%；达标后固定方法，
再独立训练Nr3D/Sr3D。当前没有P2精度结论。

严格G恢复 → 新P2零残差真实起点比较 → batch8两步反向/恢复预检 →
G控制单次fit → G＋P2单次fit → 两臂正式9508行评估 → 修复/破坏、候选覆盖比较。
仅单张A100，串行占卡。按实测阶段耗时预估检查点，超时才180–300秒复查。
