# ScanRefer 候选局部视觉读取：固定首轮

本计划在读取本轮新结构的训练或开发指标前固定。沿用 §20.79 的用户范围：ScanRefer
先训，REC 守住 V99 5572/4797（9508 行），Scan Mask 守住论文
58.70/50.70/44.72%，通过后尽快 Nr3D/Sr3D REC，不等待 59/51；Nr/Sr Mask 不设门槛。
之前联合读出、P2/R1/L1 等实验的失败结论保持，均不重新扫参数。

## 唯一结构改动

保留最后一层 BiDecoderLayer 原 cross_v，以额外的候选局部读取残差补充它的输出，
随后进入原 norm_v、FFN、Box/token 预测头和 Query Mask 路径。Query 在该位置已经
读过完整文本和对象记忆，作为局部注意力的语言条件；不再增加文本池化或新的关系头。

每个候选在原 50000 个 XYZ/RGB 点中，按候选轴尺度归一化距离取最近 64 点。对这些
真实点，用原 PointNet++ 的 three_nn/three_interpolate 从 2048 个 SA1 seed 的
128 维预训练特征插值。局部 Key/Value 读取 SA1 特征、RGB、米制相对坐标和归一化
相对坐标；144 维、4 个头，输出 288 维残差。没有体素主干，也没有增加输入点数。

已有实际前向记录出现负预测尺寸，因此邻域半尺寸以 0.05 米为下限，仅供局部距离与
位置编码使用；不修改原预测框、GT loss 或 evaluator 的尺寸规则。按 32 个 Query
分块计算距离，避免 B12×256×50000×3 的整块临时张量。没有空球 seed0 替代路径。

输出投影权重/偏置为零，初始化时应与原模型一致。SA1 插值不会凭空恢复丢失的扫描
信息；最近 64 点也不保证完整覆盖大目标表面，原全局路径仍提供场景及物体上下文。

## 预检与固定终点评估

先运行 4 项 CPU 单元检查及原 Python 3.7 编译/入口，再对固定 16 条 fit 表达（B12+4）
检查真实 Box、token、两类 Mask 和 V99 输出的零初始化一致性、实际 GT 梯度及显存。
另在一次性内存模型上做 2 步更新，确认初始零输出投影之后，梯度能进入 point/Q/K/V
路径。预检权重不保存、不进入正式训练，训练重新严格加载 E71 并初始化新分支。

训练起点/终点记录全部6887开发行的同输入 REC/Mask、修复/破坏和原始输出；固定
终点再进行一次9508行 ScanRefer 正式配对验证，报告原生输出与完整V99输出的区别。
开发集不挑 epoch、不扫描门限，也不把已见训练场景上的严格不退化当作泛化门槛。
此安排只适用于新结构，不改变此前已封存实验的预注册判定。
真正的晋级由9508行的用户底线决定：REC至少5572/4797且不低于同输入保护V99，
Scan Mask三项达到论文线。仅正式通过后进入Nr/Sr，不宣称预检或低训练loss等于收益。

## 存储与运行

复用四份现有只读预训练文件；实验源码单独冻结，保留原源文件及SHA来源。
只保存两臂的固定终点和必要恢复点，不复制E71到每个run。约需1.3GiB终点存储，
启动前已观测可用10.22GiB。失败终点审计后按用户授权清理，保留逐行指标和训练证据。
时间先按上轮数据加载/前向实测估计，再用本轮首段步速修正。接近预计终点前五分钟
读取进度，之后240秒间隔；不高频轮询，不与其他GPU任务并发。

实现：models/candidate_local_visual.py、BiDecoderLayer 与 MCLN 调用处；
入口：scripts/run_scanrefer_local_visual_pair.py。此时尚无性能结论。
