# ScanRefer固定配对：直接监督Mask表达的目标几何

## 研究问题

已有硬Mask选点及分位数框没有Mask成员梯度，而评分统计仍可微。实际16条fit上的连续概率CDF原型已实现坐标损失→原始Query Mask→原生参数的梯度；同一251个候选的过线数没有崩溃，平均IoU略降。这只说明可继续检验训练机制，不是REC增益。

本配对检验：在原生GT训练之外，让当前root Query的Mask承担定位范围监督，能否改善实际硬Mask几何与完整V99。它不是教师框辅助续跑、不修改后处理阈值，也不是V44的多候选逐点监督。推理仍保留当前硬几何和V99，不宣称已去除后处理。

## 结构与目标

原网络、对象输入、文本、256个Query、匹配和部署规则不变。实验辅助`native_mask_geometry_supervision.py`仅在训练损失中：

1. 从当次原生Hungarian索引取得root对应Query，不使用固定旧编号、部署Top1或所有Top16代替实例匹配。
2. 取该Query的原生Text/Query融合Mask，对原输入点的sigmoid质量计算坐标CDF。
3. 在固定0.005/0.995分位点线性插值读取连续范围，以root GT监督中心、尺寸和GIoU。
4. 保持原生全部GT损失；只有候选臂增加`5×(center L1+0.2×size L1)+GIoU`，系数1，不扫权重或温度。

GT只进入原匹配与训练损失，不进入模型forward、CDF读取或部署选择。连续CDF不与硬框数值等价，没有用直通梯度冒充精确导数。必须同时查看连续范围与实际硬范围，不能仅凭soft误差下降晋级。

## 固定比较

| 项目 | 固定设置 |
|---|---|
| 起点 | 同一保护E71及冻结Parent/Geometry/V99、原归一化元数据 |
| 数据 | 正确mesh；既定29778 fit / 6887模块留出，无增强 |
| 控制 | native_gt：仅原生GT损失 |
| 固定候选 | native_gt_mask_geometry：原生GT+Mask几何GT |
| 更新范围 | decoder.5、prediction_heads.5、x_query、x_mask、rel_encoder |
| 参数边界 | 84项允许参数；实际两步probe中82项改变，不能强制84份optimizer状态 |
| 冻结范围 | 其余核心及全部BN缓冲；三个读出参数与元数据 |
| 优化 | model.eval，AdamW lr1e-6、wd0.0005、clip0.1，B12 |
| 预算 | 每臂一遍29778行，2482更新；相同点批次、顺序与种子 |
| 评估 | 起点6887行；唯一固定终点6887行，不重选epoch |
| 磁盘 | 仅保存84项参数与实际optimizer，结合E71重建1144项，避免完整权重副本 |

这是新损失机制的短周期对照，不是150—240epoch baseline重训。模块留出为主干以前见过的场景，仅用于筛选，不能写成全系统新场景成绩。

## 必须记录与核验

- 原生REC、完整V99 REC、原生Mask逐行记录，保留修复/破坏。
- 当前匹配Query的软几何、硬fused_t0_q0.005、GT范围及实际Query映射；检查soft改善是否落实到hard。
- 原始point SHA、源码与mesh清单、相同fit遍历；84项参数保存与E71完整重建。
- optimizer按实际参数ID映射核对；没有梯度的参数不得伪造更新次数。冻结状态/读出始终逐项检查。
- 终态CPU独立重算损失、匹配索引范围、逐行指标和晋级决定。

## 晋级与范围

固定候选在模块筛选中完整系统REC两阈值相对起点和native_gt均不退化，才执行唯一正式ScanRefer验证；不拿控制替代候选，不调温度、分位数、loss权重或选epoch。

正式Scan REC不少于保护V99的5572/4797，且不低于同次保护控制；Mask达到58.70/50.70/44.72底线。过线即接同结构Nr/Sr REC，不等待59/51。Nr至少59.82/51.38，Sr至少68.43/57.30，当前Nr/Sr Mask不设门。

若失败保留具体负结果，不扫同配置。若只soft几何改善，则属于训练代理与实际输出不一致，不能宣布硬边界或REC改善。
