**What is actually implemented**

PV-Ground receives a candidate-specific residual on its Query Mask, constructs a discrete fused-mask box, and mixes that box with the native regressed box using an axis-wise decoder conditioned on the superpoints that supplied mask extrema. A training-only objective additionally teaches the root mask to the native winning query only when that query is absent from every last-layer Hungarian match.

**Suggested positioning**

“In a PV-Ground-derived model, we condition candidate Query Mask residuals on native two-mask state and input-superpoint multiplicity, use the sources of hard mask extrema to condition per-axis interpolation with regressed boxes, and add root-mask supervision to the native highest-scoring candidate only when it is unmatched, retaining the existing inference score formula.”

That is a faithful description of the present implementation, not an efficacy assertion. The potentially defensible scientific question is whether these specific choices improve localization beyond ordinary residual correction, whole-support evidence, generic mixing, and the native criterion at the same training budget.
