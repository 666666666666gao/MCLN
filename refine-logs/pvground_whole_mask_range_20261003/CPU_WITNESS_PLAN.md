# 完整Mask成员范围表示：CPU几何核验

本项只实现下一阶段S1需要的成员范围表示，不接入模型、不预测框、不改变损失，不启动结构训练。当前归一化实验及其单一等待进程保持不变。

依据原PV尾部接口，Text Mask为1×256×M且候选维重复，Query Mask为256×M，alpha是每行一个标量；先融合logit后sigmoid。输入完整50000点的XYZ及同顺序超点ID；不把超点中心当作成员范围，不裁掉粗框外或低排名Query。

member_statistics一次统计每个有实际成员的原生SP槽：成员数量、XYZ方向32桶计数、连续一二阶矩、真实成员最小/最大范围，记录场景原点和轴跨度。仅压缩有成员的槽并保留原生ID，Mask读取使用这些原ID，没有空槽fallback。

mask_range_evidence用预测融合logit和成员数量计算点级测度下的软支撑方向分布、连续矩和成员范围摘要。通过logsigmoid加logcount的softmax实现sigmoid×count的归一化。输出不是硬Mask框，不保证真实实例边界，也不把加权最小/最大摘要冒充最终边界。32桶存在量化损失；连续矩及SP成员范围与桶信息互补，但不能恢复任意细节或已缺失观测。尚未实现可学习精修头。

复用已核实的4份现有真实训练fixture，CPU读取、逐一核对既有receipt的文件SHA及输入形状。四个场景各50000点，只有数学输入Mask：构造共享Text logit、256组Query logit与单一alpha；明确不是当前模型预测，不计算REC、Mask精度或教师目标。只用点坐标及SP ID，不用GT框/Mask或目标标签。

核验成员计数与三方向桶质量守恒、完整256候选输出形状、各轴分布和为1；对固定4个Query，将压缩表示与逐点密集计算对照，核对profile、一二阶矩、成员范围摘要、support_fraction及Text/Query/alpha梯度。CPU double前向和梯度绝对误差阈值1e-9，数学核验不代表CUDA或完整模型可运行。

另记录若仅用SP中心替代实际成员，32桶方向统计改变多少；这是4训练场景几何信息差异，不是模型收益。全程0模型前向、0优化步、0权重文件、0CUDA初始化。新鲜源码审查通过后才运行该CPU核验；当前正式训练完成和归一化结果分析之后，再决定是否把此表示接到同尾部普通精修器中做独立结构对照。
