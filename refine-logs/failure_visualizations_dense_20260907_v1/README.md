# 原始彩色网格：GT / Ours 论文式定位对照

优先打开 index.html，或 ScanRefer_GT_Ours_dense.png、Nr3D_GT_Ours_dense.png。

按用户2026-09-07提供的参考图重做：上排GT、下排Ours，逐列严格相同场景、相同相机、相同裁切，白底无坐标轴。绿色为GT，红色为留存模型预测，白色外描边提升可读性。底部保留原始表达和3D IoU。

这次使用ScanNet原始彩色三角网格，不再将5万个采样点画为小散点。五个不同场景约9.4万—23.7万顶点、17.9万—45.2万三角面，连续表面来自原始mesh的真实连接关系。保留原始颜色，不补造墙面/家具，不复制点云。为显示室内采用记录在dense_render_verification.json的水平剖切，原始未裁切网格完整保存在meshes/。

逐例把原始网格按数据集轴对齐矩阵转换，模型50000输入点到网格顶点的最近距离最大均<2e-6m。预测框、GT框、IoU、选例及模型来源完全沿用上一级cases.json；高密度网格仅用于显示，不是模型增加输入点后重跑的结果。立体框线按同一相机投影后叠加，遮挡边也显示以方便识别。

ScanRefer：受保护E71+Parent+Geometry+V99的逐级诊断记录。Nr3D：平均E57的root_only Default缓存，不等同正式评估路径。Ours仅指这些已注明版本的实际输出，不是新网络获得的成绩。Sr3D仍缺权重/预测缓存，没有制作伪造案例。

文件包括两张3560×2780的300dpi PNG，各自单页PDF、两页合并PDF、六例独立GT/Ours高清图，另有分开的GT/预测/无框场景PNG，便于排版。原始英文描述在独立图和拼图内均完整保留。旧散点诊断入口为上一级index_sparse_diagnostic.html。
