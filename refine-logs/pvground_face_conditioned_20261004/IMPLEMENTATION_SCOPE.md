# 六面条件化支撑解码：本地实现范围

当前仅实现独立Python源文件，尚未接入真实PV工厂、配置、训练入口或GPU预检，也没有参数量测量、梯度或精度结果。不能把语法检查称为模块通过真实训练。

每个候选保留六个面Query，顺序为x-、y-、z-、x+、y+、z+。每个面读取对应轴的32桶完整预测Mask支撑，以及该面16个局部成员和中心16个成员。局部成员来自当前控制相同的七处近邻；读取的成员和全局统计未被替换为GT目标或硬Mask过滤。

每个全局桶保留预测支撑质量、场景归一化位置、相对候选中心的位置和面方向。面Query保留原G语言条件Query、粗框六维场景归一化表示及对应轴的均值、二阶矩、成员极值均值、软支撑比例。极值均值仍然只是范围证据，不是精确边界。

使用共享33位置分布输出，复用已完成控制的expected_offset/decode_faces及六面目标、共同1e-6尺寸协议。输出层零初始化；真实零输出、梯度和恢复尚待预检。分布熵不能直接视为校准质量。

复用源来自pvground_boundary_distribution_20261004，其中普通分布头正式原生bbs为5616／4506。下一次实现集成必须绑定实际父G、依赖源码SHA和原生评分接口；新头从共同原G初始化，不加载普通分布头后假称同预算控制。原G冻结、seed2027、有效batch8、29778条各一次／3723次更新为拟定控制配方。

参数量、成员表示与解码方式的差异都应报告。新头没有最终语义回写、独立质量分数、教师、GT推理门控或数据集开关；全部256候选保留。六面boundary_face_state只是供后续有证据时研究回写的内部表示，当前没有参与评分。
