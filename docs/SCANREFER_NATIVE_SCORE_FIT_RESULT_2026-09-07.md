# 原生与候选适配器评分：固定512条实际输入结果

本次没有观察到评分定义差异造成Top1错误或Top16覆盖损失，不据此修改受保护Parent输入或重新训练旧读出。它结束了20.141合成反例到实际输入的检查；不是证明所有数据上的两个定义等价，也不是新的正式指标。

## 数据与实际路径

沿用正确mesh教师审计预先固定的512条等间距fit身份，来自382个ScanRefer训练场景；这些场景已被主干见过。使用同一E71、622文件源码快照、B12、seed0、无增强，逐批仅一次模型前向。模型及全部旧部署规则未修改，无优化器、checkpoint或正式集前向。

原生分数来自实际evaluator的`_position_top_indices`，SourceChoice和候选适配器从同一outputs计算。原候选规则来自受保护Parent的`candidate_rule`：每源8个、总计16个。另一个集合只作诊断，将default换为原生分数，保留原contrastive分数和预算，没有运行学习的Parent/Geometry/V99。

旧512缓存的`native_scores`实际由候选适配器写入；本次512行的点SHA、全部256框和适配器分数与旧缓存逐值相同，框/分数最大差均0。旧缓存的字段名需要按源码解释；不能仅凭旧聚合命中相同推断逐候选一致。本次才直接记录并验证了这种一致性。

## 后续决定

不把default统一化作为下一轮主训练，也不扩大这项检查到正式集寻找可调阈值。不复活冻结pair读出、普通质量头、兼容loss或教师框辅助的已封存版本。继续围绕原生REC的候选判别与实际几何输出设计新机制；必须说明新增证据和与既有训练的实质区别，不能把本次诊断包装成网络贡献。仍然ScanRefer预训练起点优先；正式REC与Scan Mask达现行底线后，及时开展Nr/Sr REC训练。
