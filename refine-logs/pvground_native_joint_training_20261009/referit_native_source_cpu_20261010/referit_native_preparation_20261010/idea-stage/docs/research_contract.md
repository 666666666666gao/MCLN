# 跨基准接口准备的研究约定

沿用已发布 B4，未创建新研究目标。所引用技能包未提供其模板文件，本约定直接根据已发布实验计划记录。

主论点 C1：候选支撑和边界来源在原生普通训练中提供真实增量。支持论点 C2：被原生选中的未匹配候选补充 Mask 责任具有独立价值。三项机制的有效性仍未建立。

跨基准最小证据：固定最终架构，从 Nr3D／Sr3D 各自作者权重独立训练，原生 REC 与对应公平控制及原 MCLN 外部参照明确分开；同模型同 Query 提供框与 Mask。来源信息或参数量的作用必须用直接对照辨别。

禁止以本地 AST、合成 CPU 目标、作者日志或 ScanRefer 终点直接评估代替跨基准完整训练；禁止在推理中读取目标 GT、新增 dataset ID 门控、双源排名或数据集专属后处理。保持 seed2027，不做多 seed。

本轮只解决已证明的初始化／标签职责接口，未运行真实数据、GPU 或训练。ScanRefer 正常实验不能被该准备工作修改或抢占。
