## Fixed acceptance scope

- Complete EG model and all published weights; strict state restoration.
- ScanRefer validation, exactly 9,508 expressions / 312 scenes, seed 2027,
  batch 8, one GPU, no shuffle, no dropped or duplicated rows.
- Author two-stage GroupFree detections (`butd=True`, `butd_cls=False`,
  `butd_gt=False`), XYZRGB, existing mesh-derived superpoints.
- Native final-layer bbs primary; bbf diagnostic. Both accuracy thresholds use
  strict IoU > .25 / .50, same checkpoint and row set.
- Preserve the author evaluator's average of regressed and mask-derived boxes.
  This is the native author pipeline, not a pure box-head result. The user
  suspended Mask metric gates, not this author's model components.
- Root/role token maps come from upstream text parsing. No GT boxes or instance
  labels enter model.forward. Ground truth is used only for evaluation.
- Eight fixed rows for execution preflight, then one full pass. The preflight is
  not a performance screen and cannot select a checkpoint or hyperparameter.
- No optimizer, no training, no automatic Nr3D/Sr3D launch. Those author scripts
  use butd_cls; dedicated published weights remain unconfirmed.

REC evaluator methods, checking exported row hit counts against those methods
batch by batch. It records selected query, raw box, mask box, averaged box, root

formal metric claim. Preserve real failures; no result-based score adjustment.
