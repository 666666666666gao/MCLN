# 完整Mask范围精修：真实PV模型预检准备

本阶段只实现真实工厂／原生损失的两步预检入口，当前归一化训练不修改、不查询、不抢占GPU。上一阶段独立CPU结果不是本阶段的结果。本阶段尚未执行，不报告CUDA通过或精度。

工程预检固定保护的原G＋官方PV父权重，重新构建原37状态任务／观测读取，然后添加10状态、400614参数的WholeMaskSupportBoxRefiner。模型源码复用已经验证的Mask后尾部槽位，输出仍覆盖last_center／last_pred_size。两组共同使用旧局部融合Mask支撑及6维粗框场景条件；区别仅为109维完整范围真实值或零值，全部256候选保留。参数数目相同不代表有效功能容量相等。预检不决定正式结构实验的共同起点或监督；待归一化正式结果分析后单独决定。

复用已执行同尾部runner的实际PV工厂、数据契约、DataProcessor、Dataset、原生criterion、G资格和AdamW，减少无关修改。本入口只允许cpu／preflight；不含正式训练、选模或完整精度评估。cpu模式仅构建、严格恢复官方父权重＋原G，再验证新增状态、形状及参数数目；真实工厂可能需要原环境的CUDA扩展，因此也不在本机代替执行。

GPU预检在唯一现有归一化控制器确认结束及完整分析后，复用认证warm环境、batch8／seed2027／LR核心与backbone均1e-5／weight decay5e-4／clip0.1。一个实际增强训练batch，两次重复更新。真实native Hungarian、完整原生loss与G替换，不使用构造匹配或数学GT。

起点检查使用实际一次完整PV前向，并从精修器捕获相同几何Query和输入，在零输出层下分别重放信息开启／关闭。两组状态相同、固定同一上游输出；这是同输入的精修器条件对照，不是跨进程完整模型逐位一致证明。另一次原生不装精修器前向核验语义／框起点和调用顺序。保留真实差异与原失败，不能自动放宽条件或重启。

原生loss_boxes的梯度必须到最终精修头；末层语义/G与原Mask损失对精修器无直接梯度（共享上游训练仍可改变语义与Mask）。单独隔离完整范围分支，核验第二步更新后对实际Text／Query Mask和alpha的梯度；信息关闭条件该分支应不在定位loss路径中。不能用局部Mask支撑梯度冒充新增完整范围通路。

模型全部状态严格内存重载，AdamW参数组、状态键、step、exp_avg、exp_avg_sq逐项比较；仍不宣称磁盘恢复或恢复后继续训练等价。记录全流程实际峰值分配/保留显存、前向及两步耗时；不以当前CPU几何搬运估计替代真实测量。不写权重文件，也不启动正式新训练。

部署入口及资源安排尚未编写或执行，须新鲜源码审查后、当前归一化终态核验后再确定。正式来源对照、3723次更新／9508表达评估仍属于后续研究，不以两步预检替代。
