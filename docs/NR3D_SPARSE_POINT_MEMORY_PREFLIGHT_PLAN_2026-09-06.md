# 真实点—体素局部记忆原生预检

要检验的机制：直接从相同原始采样点生成细尺度邻域特征，并按实际点成员进入超点，
能否为Mask提供不同于末层1024 seeds和SA1插值的局部证据。当前只做输入/接入/梯度
预检，0优化器更新、0模块留出评估、0正式验证，不构成精度证据。

第一版固定2厘米体素，以每个场景XYZ最小值为原点，floor量化并保留每点inverse索引。
每点输入为体素内连续坐标偏移及原生RGB，6→32的Linear/LayerNorm/ReLU编码后求体素
均值；依次使用32通道SubMConv、stride2的32→64稀疏卷积、64通道SubMConv和64→32
逆卷积。细尺度skip相加，逆映射回原点，与原点编码拼接成64维特征，按实际superpoint
成员求均值，零初始化64→288投影进入原super_grouper输出。保留原邻域索引和后续头。

该分支使用原50000个XYZ/RGB点，不读取SA1/seed特征，不增加输入点，不用实例GT清洗。
同体素内的点仍保留各自连续偏移、颜色及原超点归属；没有将体素逆映射描述为恢复新观测。
新分支用LayerNorm，不新增BatchNorm运行统计。PointNet++全局路径和整个原生模型冻结。
此次Mask输入变化可能影响Query Mask、Text Mask和alpha，原Decoder Query/Box/排名不变。

依赖已通过的独立稀疏环境及GPU算子检查。使用固定M3的16条fit/16扫描，B4、augment=False、
seed0、同parent和612源码/36数据文件清单。先运行3项CPU点映射测试及原Py3.7编译，
实际统计参数量/形状，不依赖手工计数作启动依据。原模型数值设置沿用既有预检；不因为
独立算子参考检查曾关闭TF32，就改变受保护MCLN的全局数学设置。

每批执行原生、零残差、固定扰动3次forward，总12次。零初始化需精确复现seed、Query、
框、分数、原Query/Text Mask及alpha；输出矩阵梯度须有限非零，其他新参数首批梯度应为0。
随后投影固定为0.001倍矩形单位矩阵，要求REC及Decoder Query不变、原始Query Mask有
变化，全部新参数的原生Mask损失梯度有限非零。结束恢复全部参数，核对原模型buffer和
源码、数据、parent未变。预检扰动不是训练，也不用于选择超参数。

同时记录真实GPU点映射：50000点inverse索引完整、RGB保持、坐标重建绝对误差≤1e-5米，
占用体素数、网格尺寸、最大体素点数，以及跨多个超点的体素/点数量。跨超点不等于跨
GT实例，混合比例不作为模型性能。输入统计仅来自这16条fit表达，不外推全基准发生率。

预计数据初始化和12次预检约3–6分钟，首次180秒后观察，随后240秒。与其他GPU任务共用
既有锁。根据实际显存、吞吐和梯度结果再固定配对学习预算及原生对照，当前未注册训练。
此分支不会单独改变REC，后续若支持局部证据价值，再研究同一记忆到目标身份推理的连接；
三个数据集正式目标仍是完整目标，不能以输入预检通过替代。O1/B/C1/L1旧设定保持封存。
