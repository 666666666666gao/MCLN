# 对象外观训练前的完整Nr3D训练场景输入检查

683槽的非空证据只覆盖16个场景。外观原型按框半尺寸归一局部点，训练前必须确认
其非空、正尺寸合同在拟用输入范围内成立；本检查不训练、不改模型或裁剪规则。

当前代码在每次getitem复制scan.orig_pc，无增强时_get_pc直接拼接原生RGB；50,000点
已经保存在train_v3scans.pkl中，不在每条表达getitem重新采样。_get_scene_objects由
同一scene点和对象生成输入框，butd_cls使用这些框。因此这里对32919条Nr3D训练表达
涉及的全部511场景各取CSV第一行，检查完整有效对象集合，而不重复511个点云数万次。
执行时逐场景核验实际点XYZ等于orig_pc、RGB等于原生颜色减mean_rgb，保留hash。

输入沿用已锁定的612源码、724数据文件。检查每个有效对象的原float32框裁剪点数
以及各轴尺寸；记录全部空裁剪/非正尺寸槽的场景、对象索引、框和点数，不读取GT
实例成员来清洗输入，不扩大边界、不引入替代点。没有正式验证表达或模型质量统计。
若发现违反合同的真实输入，先依据记录决定归一方式或缺失外观的定义，再改原型。

入口scripts/audit_nr3d_all_object_crop_inputs.py，CPU-only、0原生/GPU forward、0更新。
报告区分“审计完成”和“合同通过”，即使发现不合格槽也保存完整证据并正常结束审计。
这个结论只覆盖固定无增强的Nr3D训练场景输入，不外推增强后的框或其他数据集。
