# 实际PV预检运行安排（仅准备）

在当前 normalized 原控制器实际完整结束、9508结果收集分析和新鲜终态审查以后，运行已有工程预检。当前尚未部署、查询资源或运行新完整模型。

复用现有认证 warm 环境、官方PV权重和保护原G；不改变已审阅的模型、loss、spec或当前训练。一个全程GPU锁控制器串行执行 local_range、whole_range，各实际batch8两步；起点/调用顺序/分支梯度/内存恢复检查仍由既有runner执行。此工程起点不预先决定后续正式结构实验的父权重或loss。

launcher 在启动前检查原 normalized 控制器已不存在、完整结束码0和GPU无compute进程；使用全新预检目录。保存每组日志、退出码、原生receipt以及控制器状态，失败停止后续组，不自动重试，不修改门槛。只产生文本，不保存磁盘权重。64MiB是预检日志余量，不能用于正式训练保存容量判断。

两组总时长暂估10分钟，不是已测时长；首次检查暂定启动7分钟后，之后240秒。实际进程与终态凭证才证明运行状态；观察失败不等于模型已结束，不因此重启。

本安排须源码审查通过才可执行，尚不执行任何启动命令；正式训练仍需实际预检结果和当前normalized终态分析。最佳权重与必要parent/保护V99/一个活动恢复保留，非最佳完成核验后及时清理，实验记录保留。
