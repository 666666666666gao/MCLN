# 固定PV-Ground原生REC读取接口

本项为后续Nr3D/Sr3D接入提供可核对的原生分数、候选过滤与Query索引，不增加新的评分头或改动当前ScanRefer运行。
入口为 `scripts/pvground_rec_readout.py:native_root_rec_readout`，支持当前固定六层、256-token模型的最终root输出。
借鉴来源是固定PV-Ground提交 `262e2592589baec7bb83a0d46aae6542d4ccedfb` 的作者Evaluator；这是其决策操作的提取，不作为本项目新方法。

## 具体规则

- 输出原始框与按作者规则将尺寸clamp到至少1e-6的框；不原地修改模型张量。
- bbs使用soft-token概率；bbf使用温度0.07的Query/token对比概率并补零到256个token。
- 主实体map将正值置1，修饰/代词/关系/其他实体map保留实际值；原生分数为主实体＋修饰＋代词＋关系－其他实体。
- Nr/Sr `butd_cls`下，与有效对象框的最大IoU严格大于0.25时保留分数，否则乘0。继续使用Torch `argsort`排序256个Query。
- 单独返回原始分数、过滤后分数、对象重叠mask、两个模式的完整排序，避免离线报告与实际Query选择混用。

这里的乘零不同于旧MCLN selector诊断的负无穷屏蔽：存在负分候选时，零分Query仍参与排序。
当前接口原样保留作者操作，不根据这一结构差异更改阈值或候选规则。
目标GT框、GT Mask以及评估难度标记不参与该函数；它读取预测、现有文本成分map和协议对象输入。
