# ScanRefer 局部视觉配对：修正 mesh superpoint 训练输入

本计划于 2026-09-06、启动本轮 GPU 预检之前固定。它接续主交接文档 §20.96，不修改历史实验结论。

## 已有证据与本轮问题

完整 9,508-row 正式复核 v3 使用受保护 V99 对应的 mesh-derived superpoint 输入，控制组 REC 为 5570/4797，旧数据训练的局部视觉模型为 5549/4744。配对净变化为 −21/−53；ScanRefer 三项 Mask 底线通过，REC 不退化要求未通过。控制仍比历史最好 5572/4797 少 2/0，不能声称精确恢复历史源码或历史成绩。

此前配对训练复用了旧命令构造器的 DATA_ROOT。旧路径与 mesh 数据视图有 206/312 个验证 superpoint 文件不同；新的数据视图将训练和验证 superpoint 分别指向已修复的 mesh 目录，其他输入与原目录共享 inode。这是实际输入错误，值得单独重复，不能由此预先认定模型会改善。

本轮只回答：在与受保护系统一致的 mesh superpoint 输入上，从相同预训练起点重复同一局部视觉配对实验，结果是否改变？原生 REC 与固定 V99 读出的不一致继续作为诊断，暂不改变评分规则、匹配或损失。

## 固定设置

- 数据根：`/root/autodl-tmp/DATA_ROOT_mcln_meshsp/`，末尾斜杠与原生 tokenizer 拼接方式一致。启动前核验 1201 个 train、312 个 val superpoint 文件 SHA；清单来自已完成的正式 v3 输入审计。
- 同一个 E71 受保护预训练起点，同一组 Parent、Geometry、V99 权重；不复用旧配对终点或预检更新后的模型。
- 核心源码仍为已封存的 614-file local-visual source；控制组为原 cross_v，实验组在最后一层 cross_v 后加入已有 145008 参数的候选条件局部点读取。无新模块、体素分支或额外损失。
- 保持已有物理场景分组、split salt、行索引：fit 29778 条/456 个物理场景；holdout 6887 条/106 个物理场景。冻结主干以前见过这些场景，因此属于模块留出评估。
- seed 0，batch 12，最后一批 6 条，一遍 fit，每臂 2482 次更新。关闭本机制实验的数据增强，不混入辅助 detection 行。
- 保持 model.eval() 的 BN/dropout/buffer 行为，仅更新 decoder.5 与 prediction_heads.5；实验组额外更新 local_visual。AdamW：core LR 1e-6、local LR 1e-4、weight decay 0.0005、clip norm 0.1。
- 原生 GT loss；Parent、Geometry、V99 读出冻结，两臂共享同一读出参数。原生损失与最终系统评分是否需要联合训练，留给后续独立实验。
- 完整 baseline 与 terminal 各评估同一 6887-row holdout，逐行保存 point SHA、REC/Mask IoU，核对冻结状态与优化器实际步数。

## 执行和判断

1. 在固定的 16 条 fit 表达上运行真实 GPU 预检：12/4 两批，零初始化原生输出和 V99 输出一致，2 次一次性更新后局部点编码及 Q/K/V 梯度非零，冻结参数、buffer、读出不变。预检不保存完整权重。
2. 预检成功后从受保护 E71 重新实例化两臂，执行上述固定一遍训练。保存每臂唯一终点及优化器状态，不保存逐步/逐 epoch 副本。
3. 独立审计训练行、输入数据、源码、参数变化和步数后，对唯一 local 终点运行一次正式 9508-row 配对评估。holdout 分数用于诊断，不选择 epoch、不扫描阈值。
4. 同一终点的 ScanRefer REC 必须同时不低于历史 5572/4797 且不低于配对保护控制；Mask@0.25/@0.50/mIoU 必须不低于 58.70/50.70/44.72%。通过即尽快训练 Nr3D/Sr3D，不等待 >59/>51 的争取目标。
5. Nr3D/Sr3D 的 REC 目标仍不低于原 MCLN 59.82/51.38、68.43/57.30；其 Mask 当前不作为晋级门槛。本轮 Scan 未通过前不启动其正式训练。

结果为负，只否定这次固定结构与训练范围；既不恢复已封存的 P2/R1/L1 扫参，也不把输入修正或预检通过计作指标增益。本轮是数据归因对照，不是单独的论文创新或跨场景泛化证明。

## 资源与保留

沿用现有 bdetr Python 3.7 / PyTorch 1.10.2 / CUDA 环境和单 A100 40GB，不安装新依赖。启动前实查 GPU 无训练进程、磁盘至少能容纳两个约 620MB 的唯一终点及日志；保护 E71、Nr3D 最好和三个 V99 系统权重。旧负实验的日志和逐行结果保留，确认不再被运行任务依赖的失败权重再清理。

按上一轮实际速度，baseline、训练和 terminal 合计预计约 3–4 小时；以本轮首阶段实际速度更新 ETA。长任务接近预计阶段结束前再观察，之后按 180–300 秒轮询，不因观察超时重启训练。
