# G：未匹配合格候选的原生语义标签替换

状态：固定设计，待实际 preflight；没有新性能结果。

## 唯一训练改动

在原生最后层 Hungarian 匹配后，对 **未匹配到任何标注、且当前原框对句子 root GT 的 IoU严格大于0.5** 的 Query，将末层 soft-token CE 的 no-object目标替换为原生 root文本目标。不能把两个Query编号当两个实例，也不将已匹配其他目标的Query改标成root。

保持原生 root目标 `0.6*positive + 0.2*modifier + 0.2*pronoun + 0.1*relation`，包括非单位质量、熵常数及原有未匹配权重0.1；归一化仍为该层匹配标注总数。无新增权重、温度、top-k或扫描。IoU及选择脱离梯度，输入模型时不含GT。

令 R 为上述选中集合，N 为原生匹配数，t 为原生root目标，l为log-softmax，则：

`Delta = (0.5/7) * (0.1/N) * sum_R [sum(t*log(t+1e-6)-t*l) - (log(1+1e-6)-l_noobject)]`。

总训练损失为 `native_loss + Delta`。这是原有CE项的替换，Delta允许负值，不是额外非负辅助损失。记录旧/新被替换CE、带系数修正、Query数、样本数和匹配数。其它层CE、原对比对齐、Box/Mask及其它原生损失全部保留；因此仅声称移除末层soft-token标签冲突，不声称消除全部损失中的候选竞争。

Hungarian、Box/Mask匹配、回归梯度、bbs/bbf推理函数均不改变。0.5资格只用于训练GT标签；不把合格框认定为已证明语义身份正确。它可能仍含实例歧义，需终态检验。
