# Current implemented method, read-only novelty scope

The user requests a PV-Ground method with three effective contributions inside the ordinary training network, rather than a post-hoc ranking system. This check must distinguish current implementation from aspirational labels; it must not modify or launch the active engineering/normal-training source.

Current compute sources are in ../source. Fourteen computational files are inherited from the first native source except train_dist_mod.py's per-construction copy.deepcopy fix. The registered implementation uses three components:

1. CandidateMaskSupportCorrector: a Query-specific residual to native Query Mask logits before the original text/query logit fusion. Per occupied superpoint, inputs are projected language-conditioned Query and superpoint content, text/query/fused probabilities and disagreement, fusion alpha, and log(1+member count). The implemented parent uses use_box_geometry=False: its nine coordinate channels are zero, so it is not an empirically verified geometric-position module. It does not change the original text/query mask fusion rule or add a score head.
2. ExtremalSpanMixer: corrected native fused foreground supplies the member-coordinate hard XYZ extent. For each of six faces, collect all tied superpoints that actually supplied that extreme, aggregate their live content, mask agreement, member count, and relative range statistics; pair opposite faces. A learned per-axis gate in [0,1] mixes reference-mask and native-regression center/size with the same coefficient. It emits one final box per candidate, leaves all 256 candidates, and uses native last/bbs ranking. The whole_support direct control keeps the same parameter count but pools whole foreground for every face. Its frozen paired formal counts whole5676/4921 versus extremal5677/4920 do not establish an extremal-specific gain. Fixed half mixing also passed the numerical metric targets; no claim that any learned gate is already necessary.
3. selected_query_mask_loss: training-only native last/bbs winner is detached; if that Query is absent from ALL original last Hungarian matches, give its own Query Mask and its fused Mask root GT focal/dice targets. Matched root or other instance remain original responsibility. At most one extra Query per expression, actual batch mean; original Hungarian matching unchanged, no extra inference selector. This is additional deployed-candidate supervision, not the previously tested many-mask-qualified geometry loss or G's high-Box-IoU CE replacement.

The normal plan jointly updates original trainable PV core/backbone and additions, preserving native RoBERTa freeze. It starts with retained G/support/span weights and new optimizer. Existing best5677/4920 came from frozen adaptation, not this normal run; three effective contributions remain unproven. The current discrete hard extent/source choice is not a fully differentiable mask-to-box path.

Novelty claims to assess, not approved claims:
A. Candidate-specific support correction driven by native shared-text/own-query disagreement and actual observation counts.
B. Boundary-source provenance, rather than generic learned mask-box fusion: use actual member extremes and opposite-face evidence for per-axis trust.
C. Deployment-selected but unmatched query receives direct root segmentation learning while protected original assignments and unique inference scoring remain.

Obvious controls required before claims: plain residual Query/SP-content correction versus mask-state/count conditioned correction; whole foreground versus extremal-source same-capacity decoder; a generic constant/scalar/axis gate without boundary provenance versus evidence-driven gate; native loss versus selected-winner extra Mask target at same init and budget. Teacher, additional score branch, or new source-selection fallback are not part of this method.
