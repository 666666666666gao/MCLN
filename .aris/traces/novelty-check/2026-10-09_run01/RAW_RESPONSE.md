**C1：融合 Mask 成员极值作为框参考**

源码支持的精确定义：每个候选使用原有融合 logit 的 sigmoid > 0.5 前景，将所选 SP 的实际成员坐标上下界合并为参考框；所有 256 个候选均保留。无有效范围时使用原先框的既有处理有实际无效案例支持，不属于新的创新点。mask_reference.py:18–28 是核心实现，83–117 给出原始成员极值核验函数。六面输出为零时，解码偏移严格为零，最终框就是该参考框；因此这一状态的收益不能归功于“学到了更好的六面分布”。

最近、最危险的同任务重叠是 **EG-3DVG**：§3.3 将预测 SP Mask 映射回其成员点，计算紧包围框，再与 MLP 框按 Eq.(3) 的 0.5 权重混合。可验证的窄差异是：当前使用 PV 原有 Text/Query 融合支持作为每个候选的直接参考；参考状态输出纯 Mask 框，而 EG 使用最终框混合。仅仅把它叫“空间参考”不会扩大这一差异。[EG-3DVG 原论文](https://openaccess.thecvf.com/content/CVPR2026/papers/Park_EG-3DVG_Expression_and_Geometry_Aware_Grounding_Decoder_for_3D_Visual_CVPR_2026_paper.pdf)

**UniVLG** 已研究以 Mask 解码替代框解码，并对 Mask 包围框加入 L1/GIoU 监督；还直接讨论少量远处点及多个同类实例污染 Mask 后造成大框。因此，“首次发现支持污染导致框膨胀”也不可用。它使用 RGB/RGB-D 与联合训练的 Mask 解码器，当前则是冻结 PV 主体后的末端改动，实验设定和更新位置不同。[UniVLG §3.1、A.10](https://arxiv.org/html/2503.10745v1)；[ICML 2025 出版记录](https://proceedings.mlr.press/v267/jain25b.html)

Mask DINO 已从预测 Mask 得到解码器初始框；D-FINE 已有参考框、非均匀边界分布与残差偏移。本地 boundary refiner 甚至注明 D-FINE-style knots。不能把通用 Mask 初始化或分布边界回归声称为首创。[Mask DINO §3.5](https://arxiv.org/html/2206.02777v3)；[D-FINE §4.1](https://arxiv.org/html/2410.13842v1)

C1 结论：**PROCEED WITH CAUTION**。目前可写为具体集成与证据支持的设计选择，尚不足以单独支撑宽泛新范式。需要固定同一父模型、输入和选择分数，直接比较原始回归框、纯 Mask 框、EG 式 50/50 混合框；若坚持“实际成员极值”是关键，还需对照 SP 代表点范围。Text-only / Query-only / 原生融合范围用于证明融合支持的具体作用。零输出状态必须单列，不与已学习几何头合并计功。

**C2：候选 Mask 支持残差修正**

实际实现是 27,841 参数的共享 MLP：Query 288→32、SP 视觉特征 288→32，加 Text/Query/fused 概率、两者差值、融合权重、成员数；content 分支的九个显式框几何输入为零。它修正 Query Mask logit，再走原融合与成员极值，未新增排序头。见 mask_support_corrector.py:16–52、70–84 和 model factory:17–28。

最近的继承关系仍是 MCLN 和 3DRefTR 的 Query/SP Mask 预测；可核验增量是“在原有 logit 后增加同时读取 Query、SP、两支响应与成员数的残差修正器”。语言条件 Mask、Query—SP 交互、原分数选择 Mask 均非新概念。[3DRefTR §3.3、3.6](https://arxiv.org/html/2308.11887v2)

Relation3D 已让 SP 反向读取 Query，并用实例对比监督更新 SP；它还由预测 Mask 构造框以编码 Query 间几何。AQ3D 的 2026-08 预印本也通过 SP 读取 Query 后重新计算 Mask。它们与当前“冻结主体、末端逐 Query/SP 残差 logit”不同，但排除了“首次用 Query 内容修正 SP/Mask”的宽表述。[Relation3D §3.4–3.5](https://arxiv.org/html/2506.17891v1)；[AQ3D 方法与 Mask Refinement 消融](https://arxiv.org/html/2608.30618v1)

C2 结论：**PROCEED WITH CAUTION**。具体薄弱点不是领域拥挤，而是目前无法区分有效内容交互与额外 MLP 容量/微调。现有审计支持相同父前向内仅 +1 / +11 个 Box 命中；历史独立前向 +1 / +3 有父模型漂移，不能全算训练贡献。最低直接对照应包括零残差父模型、当前完整 corrector、去掉 Query/SP 视觉内容的相同容量响应修正器；若要把它写成独立方法贡献，还应与同预算原生 Mask 投影微调比较。优先量化同一选中 Query 的前景修复及框变化，不能只展示可挑选的总分。

**C3：给原生打分选中、且未匹配的 Query 补充 root Mask 监督**

这仍是提案。当前 matched_mask_objective.py:39–51 只对匹配 Query 使用其各自 GT Mask，57 行明确记录 expanded_positive_queries=0。合理的精确定义为：令 q*=argmax 原生 last/bbs；仅当 q* 未出现在任何原有最终匹配里时，给它增加该表达 root 的 Query/fused Mask 监督。原 matched 损失、每个其他实例的责任、分数路径及部署的 256 个候选全部保持。它是一种受限的额外正监督，不能包装成“首次一对多”或“完全保持一对一目标”。

| 最近先例 | 真正重叠 | 可核验差异 |
|---|---|---|
| MS-DETR | 在原有一对一之外给更多 Query 正监督 | 其正样本由 GT 相关分类分数/IoU 的 top-K 匹配产生并涉及额外预测监督；C3 只增加原生最终赢家且尚未匹配者，更新 Mask，不改排名。 |
| iFAN | 明确研究高分 Query 与最佳 Mask 不一致，以及未匹配竞争者 | 它校准质量分数、压低高分坏竞争者，并蒸馏较好中间层；C3 固定赢家和分数，训练该赢家交付 root 支持。 |
| BS-O2G | 分析匹配责任与分散在其他 Query 的有用信息 | 它保持正样本与目标不变，使用图传播和梯度共享；C3 实际增加一个 Mask 正责任。 |
| SegmentAnyTreeV2 | 3D Mask 的一对多监督已有近期实例 | 它按 Query 种子所在体素的 GT 实例身份分配；C3 按表达相关原生赢家选择，且保留既有匹配。 |

方法依据：[MS-DETR §3.2–3.3](https://arxiv.org/html/2401.03989v1)、[iFAN 方法](https://arxiv.org/html/2608.03216v1)、[BS-O2G 方法](https://arxiv.org/html/2609.26092v1)、[SegmentAnyTreeV2 §3.7.2](https://arxiv.org/html/2606.08206v1)。3DRP-Net 的 IoU 排序软标签也是必须区分的对象：它优化 referring score，不是固定 score 后补充赢家 Mask 监督。[3DRP-Net §3.3–3.4](https://aclanthology.org/2023.emnlp-main.656.pdf)

C3 结论：**PROCEED，早期创新检查通过**。没有找到包含上述完整约束的已发表方法。它比再次增加语义 readout 更有当前证据针对性，但还不能预测精度。关键未测事实是训练时 q* 分别处于“匹配 root / 匹配其他实例 / 完全未匹配”的数量与错误结构。C3 按定义不会修复第二类；不能把所有零 root 重叠错误都归因于第三类。

最低实验为 matched-only 与 matched+selected-unmatched 的同种子、同初始化、同 batch/更新数配对。原 matched 项的归一化保持不变，新项单独声明归一化和权重。记录 eligible 数、root 身份、所有原 matched 对不变、分数和选择索引不变。要证明“选中者责任”优于泛化正样本增量，还需一个等额额外正监督对照，例如随机未匹配 Query 或明确规定的 GT 匹配正样本；不要只比较有/无更多监督。

**应由哪些真实问题指导优化**

当前 3909 个 @0.25 错误中，3074 个与 root 框完全不相交；3367 个与另一已表达 GT 的重叠高于 root。后者只使用 141 场景中 2068 个已表达目标，不能等同真实实例识别标签。它支持优先检查“最终选中者到底获得了哪种训练责任”，不支持直接认定一个新 ranking head 会有效。

在历史错误选择的 191 个成员案例里，760/761 个过伸面只能由纯背景 SP 提供可能坐标来源；180 个缺失面之外都有观测到的 target 成员。该小面板不是总体抽样，当前前景成员未被重建，不能外推流行率；但它使“先细分混合 SP”缺乏优先依据。现在更直接的对象是支持误纳入/漏纳入，而非先增加几何描述维度。

还有一个源码上的硬约束：extent_reference 在阈值和 min/max 前 detach 了 Mask logit。**直接往当前输出框上加 L1/GIoU，并不会经此路径训练 corrector。** 若之后研究面向边界的 Mask 监督，必须明确可训练的 logit 路径；不能把挂在断梯度输出上的 box loss 当成新有效模块。

优先顺序：

1. 保留 5599/4859；结束本次失败 readout 的独立终端审计，不重启预训练复现。用训练数据记录 q* 的三类匹配责任及可受 C3 影响的覆盖量，可并入下一次小实验预检。
2. 先做 C3 最小配对试验，并记录选中 Query 的 Mask/框修复、损伤与原分数不变。若 eligible 很少或收益来自一般额外监督，按证据调整定位，不扩大术语。
3. 并行于方法整理，补上 C1 的原始框/纯 Mask/50% 混合直接对照，厘清当前优势是否只是已知 Mask 框选择。C2 先验证输入的实际作用，不增加新几何通道。
4. 只有支持误差仍是剩余可修复瓶颈时，再设计具有有效梯度的支持边界监督；当前材料不支持先追求混 SP 细分、更多质量分数或更复杂语义分支。
5. 最后在同一完整模型上证明三个贡献的直接消融和联合门槛；再按用户顺序进行 Nr3D/Sr3D 独立训练，仅 seed2027。单 seed 结论应明确范围，不要求额外 seed 才能继续。

可用于提案的一句话定位是：**在冻结原生文本排序和完整候选集合的 PV-Ground 上，将预测支持直接用于定位，并研究补充实际部署赢家的 Mask 责任能否修复匹配训练未覆盖的支持错误。** 这是待验证命题，不是已经证明的三贡献结论。
