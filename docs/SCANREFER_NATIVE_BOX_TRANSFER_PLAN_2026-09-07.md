# ScanRefer 原生框几何转移：先验证有效目标与梯度

当前完整目标仍是 ScanRefer 保持 V99 REC 58.6033/50.4523 并争取59/51，Scan Mask满足58.70/50.70/44.72底线，随后训练Nr3D/Sr3D使REC不低于原MCLN。此文不改变验收线，也不将局部检查当作目标完成。

冻结读出兼容配对已完成且未通过：系统REC相对起点−2/+16，相对native_only +3/−7。它优化的是连续读出损失；没有把冻结教师选择的实际几何框作为原生回归目标。本次先检查后一种转移是否具有可用监督。这是性能衔接实验，不能作为新结构或完整DETRDistill复现宣称。

## 数据与已有证据

旧512条教师审计的入口继承mixed DATA_ROOT，不能直接作为正确mesh教师标签的依据。新审计固定同一512条fit身份，在`DATA_ROOT_mcln_meshsp/`逐文件核对1201份训练superpoint，加载受保护E71/Parent/Geometry/V99，保存原生256框、Top16×7变体、GT root、原生Hungarian匹配、最终教师框及输入点云SHA。无优化、无正式验证；旧审计保留。

## 首个训练机制

先只测试几何能力转移，保留原有Query、文本响应及Mask路径。允许更新的参数仅为最后原生预测头的`center_residual_head`和`size_pred_head`，均从E71加载；模型eval模式，冻结BN运行状态。不是新建重排器或新评分源。

每次学生forward后，复用当次原生Hungarian中root目标的Query。冻结教师在同一输入上先按部署规则选择最终框；GT只在训练loss中判断这个框是否过0.25，以及是否优于当次学生root匹配框。权重为正的IoU差，并在有效样本中归一化；教师较差时辅助权重为0。回归项沿用现有`5×(中心L1+0.2×尺寸L1)+GIoU`。教师框detach，不将旧Query编号绑定到学生，也不替换原生GT监督。

第一项真实输入probe用原训练split中已固定的16条fit记录，比较原生GT梯度与教师框梯度，进行两次一次性更新，验证几何头得到梯度、冻结参数不变、Query/语义响应/原始Mask不变，并记录原生框确实改变。没有新权重或正式指标。若mask或查询输入实际依赖末层框，先修正方案，不能隐瞒此依赖。

probe通过后，预期使用同起点、同数据、同更新步数的`GT-only`与`GT+teacher-box`配对。完整训练设置须在启动前绑定，且不能据probe中的loss下降宣称精度改善。首先分别报告原生REC与完整V99 REC，满足既定Scan晋级条件才转Nr/Sr。本实验本身仍保留V99作为教师及系统比较；只有原生结果达到保护线，才能宣称推理不再需要原来的后处理链。

## 边界与停止条件

当前代码只实现训练损失，没有新模型质量结果，也没有启动新的长训。此机制专门回答“几何收益能否进入原生回归”，不能宣称解决复杂语言消歧。GT条件筛除错误教师只用于训练；部署不可读取GT、teacher sidecar或训练缓存。若教师没有可用的几何改进、辅助项无梯度、或变更越过既定参数范围，不启动配对训练。若完整配对不通过，封存该配置，不在已消费留出集上扫权重、LR或epoch。

参考：[DETRDistill论文](https://arxiv.org/abs/2211.10156)、[官方代码](https://github.com/BIVLab-USTC/DETRDistill)。借鉴的是动态预测需要对应后转移的原则；本项复用学生自身GT Hungarian绑定单个指代root，与论文完整集合、特征和Query先验蒸馏不同。未复制其实现代码。


## 2026-09-07 固定配对设置

实际16行probe已通过（14行有效教师监督），5项原环境CPU测试通过。下一项固定候选gt_teacher_box、控制gt_only；正确mesh，E71预训练，原生GT监督不变，仅最后中心/尺寸头16项参数更新。两臂model.eval，AdamW lr1e-6、wd0.0005、clip0.1，teacher loss权重1，B12，一遍29778fit行=2482更新。6887模块holdout按相同输入做完整前后评估，不能当作新场景正式集。

单独报告原生与完整V99。候选系统REC两阈值均不低于零更新及gt_only才进入固定正式Scan验证；原生结果未达到V99前不声称去后处理。正式Scan达到现行REC/Mask底线即接Nr/Sr的REC训练。失败则封存该配置，不扫权重、LR或epoch。

输出为两份16参数+优化器小终点，绑定E71 SHA；终态前实际重建完整模型并逐值核对。独立CPU审计自动接续。记录全部fit身份、点SHA、教师框和root，核验GT支持权重仅进入训练目标；不把GT筛选用于推理。当前是staged，启动证据另记。
