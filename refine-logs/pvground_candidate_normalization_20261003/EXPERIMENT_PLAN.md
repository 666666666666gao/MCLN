# 同对应集合下的归一化控制

状态：代码审查及原生CPU、真实batch8两步预检完成；正式normalized/train已启动，无新精度结果。

本轮一致性组在9508条原生bbs上相对控制净+8／+34，仍低于原G−19／−38。现有结果只能评价对应扩展与有效权重变化的整体策略。下一项保留相同G资格集合、原CE替换及原生对比公式，仅改变扩展后最后层对比项的计数分母。

设原匹配对应数为N，新增G合格对应数为A。已完成版本使用L_expanded/N；下一版本使用L_expanded/(N+A)。原最后层对比项先移除再替换，其余层及框、Mask、CE损失不变；不会在原项上叠加一份完整对比loss。

这一控制测的是最后层扩展对比项的归一化作用，会同时缩放该项中的原对应、背景和新增对应，不宣称只降低新增正例权重或分离出纯标签收益。N与A来自同一次训练Hungarian匹配及G既有资格接口；不引入推理GT筛选，不删除任何低排名候选。
