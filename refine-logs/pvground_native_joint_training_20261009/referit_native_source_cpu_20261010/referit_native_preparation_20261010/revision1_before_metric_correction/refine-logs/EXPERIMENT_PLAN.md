# Nr3D／Sr3D 原生训练接口准备

日期：2026-10-10。属于已发布实验计划 B4，当前只准备源码；ScanRefer 活动训练与其 08:19 首次观察安排不变。

## 目的与范围

固定最终模型后，从两个基准各自的作者 PV-Ground 权重独立训练同一结构，检验 ScanRefer 上成立的机制是否在其他基准仍有用。当前 G/A/B/C 结构只是待核对的共同候选，不提前固定为最终论文版本；如果 ScanRefer 结果要求改变结构，跨基准源也须同步到同一版本再训练。

这不是新增模块或数据集专属推理规则。模型 forward、硬预测 Mask 参考、A 支撑修正、B 三轴融合、唯一原生 bbs 保持相同；变化只在初始化和训练期标签接口。没有部署、GPU 调用、真实 loader／模型运行或新精度。

## 初始化

- 原核心：严格加载对应作者 Nr3D 或 Sr3D 的 `model` 状态，不加载 ScanRefer 的 G 1072 项 delta，也不承接 d06/f989。
- 新增 G 读取结构、A、B：新初始化，固定 seed2027；C 无参数。A 输出层为零；B 中性门控为固定 0.5 的初始值，因此整个方法的 E0 不等于原版作者模型。
- 预计结构状态数仍为 1234→1271→1295，实际构建与完整保存／恢复尚待验证，不能将源码断言计为验证通过。
- 使用完整正常训练入口，优化器与调度器重新初始化。后续采用与 ScanRefer 相同的训练职责，不把冻结头适配替代成跨基准完整训练。

## 必要接口修改

1. 启动入口允许本次 Nr/Sr 单一任务和对应作者权重，继续单卡、batch8、seed2027、6 层 Decoder；没有默认启动检测混合或 GT 对象输入。
2. G 的 root 文本目标按原 criterion：Nr 为 0.6/0.2/0.2/0.1，Sr 为 0.625/0.125/0.125/0.125；新增 CE 修正外部权重 Nr/Sr 为 1/(6+1)，ScanRefer 保留 0.5/(6+1)。原匹配、其他实例、定位和对比职责不变。
3. G 与 C 按真实 `sample_dataset` 排除 `scannet` 检测行；`language_dataset` 仍决定原 criterion 的任务权重。源码中前者来自当前 annotation，后者来自 `self.test_dataset`，两者不能混用。
4. 表达行要求 root 为首个有效 GT；已匹配候选按其真实目标保留，anchor／其他匹配实例不会改成 root。C 只为原生实际选中的未匹配 Query 增加自身／融合 Mask 目标，仍按整个实际 batch 平均，检测行贡献零。

这些分支来自已核对的实际数据接口，不是为假设样本添加 fallback。不会只删除原来的 ScanRefer 断言就宣称移植完成。

| 阶段 | 内容 | 当前状态 |

CPU 面板只能验证目标和保护路径，不证明真实 root 对应或精度。完整训练轮数、更新数和时间必须以各自实际 loader 长度及真实阶段耗时补齐；不能照抄 ScanRefer 的每轮 4583 次更新。已有整体 B4 目标是超过各自对应 baseline，同时保留同结构定义和公平起点；不因本次接口准备降低总目标。

## 后续真实检查与风险

- 验证不同作者 checkpoint 的完整 key/shape/dtype 及当前 spconv/VSA 接口；不能用 ScanRefer 的实际构建代替 Nr/Sr 构建。
- 原生评价仍用该基准的真实表达 map；只检查函数源码等价不足以保证实际 tokenizer／loader 相同。
- G 保留原 CE 修正责任；C 的额外 Mask 目标没有同时解决未匹配候选原有语义／对比职责。其是否有效仍需直接控制，不能称所有监督已经一致。
- 真实跨基准训练保持单 seed、单 A100 串行；保留最好及活动恢复权重，已归档无效状态及时清理。没有当前精度或显存证据就不自动排队训练。

成功要求：同一完整方法在两个基准的原生 REC 两阈值超过对应公平控制，目标、对象协议与训练历史如实报告；源码或 CPU 检查不是成功指标。
