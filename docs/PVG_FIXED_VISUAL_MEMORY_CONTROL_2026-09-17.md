# E：固定预训练视觉记忆的同预算训练对照

本方案不沿用§20.217的父BN混合状态，也不把128训练行的0/+4视作双阈值成功。它检验不同的问题：新增多源/观测/任务读取与视觉记忆同时更新，是否不利于短周期预训练适配。当前A/B/C/D均更新视觉骨干；尚无这一固定视觉记忆对照。结果只能支持训练策略，不能作为新的架构创新或单独BN因果贡献。

## 唯一训练机制变量

复用D的完整PV-Ground与观测状态、语义/几何读取结构，从同一官方Scan epoch81重新初始化；不加载失败D终点。将完整`backbone_net`参数requires_grad=False，且在每次model.train()后使backbone_net.eval()。其原始点、稀疏体素、BEV及VSA参数和buffer全部固定为父值；不重新提取离线特征，输入增强仍在线生效。文本编码器保持原冻结规则，其他参数按D原范围训练。

固定的是整个视觉记忆函数，不是只冻结BN。此变量同时改变骨干可学习性及训练模式，不能用结果分离二者贡献。源投影/注意力、编码器、decoder、语义/框/Mask输出继续原生GT与原自一致性目标训练。无新loss、路由Gate、采点、体素窗口、后处理、质量头或梯度冲突机制。

## 不变的协议

- ScanRefer正确mesh、检测框增强顺序、VSA排序、同一source_port。
- 固定seed2027、batch8、29778 fit行恰好一遍、3723步；6887模块留出，预训练见过的场景。
- LR/backbone配置仍1e-5，AdamW weight decay0.0005、clip0.1；骨干组为空，不另扫LR。初始新reader随机数与D一致。
- 主输出bbs，bbf诊断；Mask全部损失保留。初始和固定终点各完整评估一次；不按中间loss/快照选权。
- 复用已完成D作为同预算控制，不重训baseline；比较自己的initial→terminal及E相对D，两阈值修复/破坏分开。
- 6887终态通过独立完整性核验及两阈值对自身起点不退化后，接续唯一预定9508正式验证。正式V99 REC5572/4797及Mask58.70/50.70/44.72保持；通过才Nr/Sr REC，不等待59/51伸展目标。

## 实际工程检查

沿用D已验证架构接口；该接口不能冒充本冻结训练模式已通过。新driver启动后执行真实batch8、增强输入、完整loss/backward容量检查，0 optimizer更新；验证骨干所有参数无grad、模块eval、全部骨干state与父一致。容量后恢复全部初始state和RNG，再进行完整initial和固定训练。任何检查失败保留日志，不静默回退为全量训练。

每次保存和终态检查全部视觉state不变；其余原冻结参数同样验证。为兼容已绑定严格恢复格式，checkpoint仍保存D原820可训练张量及buffer，但冻结骨干不产生AdamW状态。记录实际训练/冻结张量和参数数目，checkpoint及receipt标明fixed_visual_memory=True。终态审计另从父checkpoint与terminal实际字节加载复核全部backbone state相等，不能只相信训练receipt。
