# 对象外观原生读取的配对短训计划

本计划在任何对象外观训练后留出结果产生之前固定。启动依赖16条fit、12次forward、
0更新的原生预检通过，以及完整511场景/16181有效对象槽的显式边界输入合同通过。
若原生预检未通过，只处理实测接入问题，不启动本学习实验。

要回答的问题：向已有对象记忆补入框内原始彩色点证据，能否在相同的原生对象注意力
更新条件下提高最终REC，并保留Mask质量？这不同于已失败R1的框/类别记忆重评分。
它也不是体素主干或整个共享身份/任务查询方案的验证。

| 项目 | native | appearance |
|---|---|---|
| 起点 | 原受保护Nr3D parent | 同parent；对象外观输出矩阵为零 |
| 原生可训练层 | 最后一层Decoder的cross_d和norm_d | 完全相同 |
| 原生可训练参数 | 6张量、334080参数 | 相同 |
| 对象输入 | 原框位置和预测类别特征 | 加入框内原始点的相对坐标/RGB编码与mean/max池化残差 |
| 新增参数 | 0 | 5张量、41472参数 |
| 总可训练参数 | 334080 | 375552 |

appearance比native多约12.41%可训练参数，是结构增量对照而非等参数量对照。
模型保持eval，其余参数和buffer冻结。PointNet++、编码器、前五层Decoder、候选采样、
两个原生语义输出头、Box与Mask writer、Text Mask/alpha均不直接更新。
末层Query变化允许同时改变soft-token/contrastive分数、候选框和Query Mask；不是
固定候选重排实验。原REC和Mask选择、合法性过滤及Query映射保持原实现。

仅使用同一输入的50000个XYZ/RGB点和当前butd_cls对象框/预测类别，不扩框、不增加
容差、不采额外点，不用GT实例mask清洗裁剪。前置全量输入合同已覆盖本无增强输入。
采用已通过原生预检的同一原型文件；不加载C1、B、L1、P2/R1的训练artifact。

沿用既定scene划分：CSV顺序前2048条fit、262场景；holdout为6172条、98场景。
后者没有参加本新增参数训练，但主干以前见过，是模块留出，不是正式验证。
两臂2个epoch、B4，共各1024更新；无增强、workers=0、每epoch种子0/1。
两臂共用同一实际batch，记录1024个输入点Tensor SHA和行ID。
fresh AdamW lr1e-5、weight_decay.0005、clip_norm.1；原生完整loss及Hungarian匹配不变。
首批仅检查零起点输出、原生共享参数梯度一致和新增梯度连通，不执行额外optimizer步。

起点/终点各评估完整holdout一次，B16、seed1000，不使用中途质量选checkpoint。
完整起点须与已封存C1/B原生起点逐行核验；每批记录实际输入与前五层Query、seed和
Text Mask/alpha摘要，要求训练两臂和起终相同。后续Query/Box/分数变化分别保存摘要。
记录原生REC/Mask、合法Full256框上界及选中Query；合法性按实际更新后的框计算。

固定终态筛选沿用原生REC实验标准：appearance相对native终点和保护起点，均须至少
净增10个REC@.25命中，且REC@.50、两个Mask命中阈值和选中Mask mIoU均不下降。
严格使用IoU>阈值，报告修复/破坏/净变化、2000次scene聚类bootstrap及全部失败项。
通过才准备正式验证与复验；不自动升级任何保护模型。失败封存这一训练设定，
不按终态再调步数、学习率或门槛；失败也不构成对所有对象外观学习方式的否定。

保存两份独立参数/AdamW artifact，检查6/11张量、有限权重/矩、1024步、实际参数
改变及其余冻结状态。所有源码、输入、parent、原生预检和计划纳入独立SHA清单。
使用既有GPU锁，与其他GPU实验串行；根据实际训练/评估速度预计完成时间，近预计
阶段完成时再以240秒观察。没有正式验证行或自动长期训练队列。

该实验仍保留旧REC/Mask选择差异，尚未实现统一最终实例决策。正式三数据集目标
仍未完成，ScanRefer保护系统不变；Sr3D保护权重缺失问题不由此实验解决。
