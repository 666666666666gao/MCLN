# EG 最后层语义／几何读取配对实验

## 问题和边界

Nr 原生适配正式结果3970/3204，低于现有4475/3759及验收4726/4059。原生作者平均框上界7311/6396与实际选择存在差距，但不能把差距全归因于评分器。此前PV上的D相对C仅-3/+1，并未证明读取分工有效。本次只检验该机制在已验收完整EG基础上的独立效果，不声称首次任务分支或已解决梯度冲突。

## 唯一架构变量

最后层完成原自注意力、PECA文本和对象交互之后，共同Query q形成两个请求 q+W_sem q 和 q+W_geo q。两个288×288矩阵零初始化，共165888参数。两种请求分别访问作者已有GMA全局点记忆和SWA superpoint记忆；共享原注意力、归一化及FFN权重。GMA残差底座仍为共同q。训练两次读取共享随机掩码，并只推进一次原生读取的RNG量，以免扰动后续负表达前向和采点顺序。

语义输出供soft-token头和对比投影；几何输出供center、size、Query Mask以及最终superpoint refinement。候选身份、Hungarian、原生所有损失、256Query及最终bbs选择保持同一协议。不增加PV六源VSA、观测状态、G语义标签替换、质量头或V99后处理。Mask保持参与作者平均框和原生训练，验收只看REC。

## 固定比较

- 控制：已经完成的EG原生Nr适配v3，父作者Scan epoch69 SHA785f46ca595aed3a06efdfc46dc1c4b0493b212ccb66062a76f519324fd24f7e；正式3970/3204。
- 候选：重新严格加载同一作者父权重，再插入零初始化任务读取；不从Nr终点续训。零初始化CPU、真实GPU前向及RNG对照通过后才复用该控制；失败时先修实现，不以换seed补救。
- Nr32919条＋ScanNet1199×10，共44909行，复用v3同一training_order.npy和正确增强源码；batch8、5614步、seed2027、LR1e-4/backbone1e-5、AdamW、clip0.1、固定LR、原生负表达双forward。
- 真实两批优化预检后丢弃预检权重，从父权重重载做一次完整训练；512步只存恢复文件，唯一性能终点5614步，不挑epoch、不加轮次。
- 固定7899条正式评估，主输出last/bbs、同GT对象输入和作者Mask/Box平均及支持过滤；bbf和oracle只作诊断。比较自身起点、原生同预算终点和项目保护/验收线。

## 顺序与判定

1. CPU实际作者decoder/head参数行为检查：零初始化train/eval输出及RNG、独立分支干预、梯度和严格状态恢复。这不是实际场景精度。
2. 等现有Sr正式评估释放GPU；真实固定训练batch比较完整原生/任务网络的起点输出、损失、RNG，随后两步优化确认梯度、显存和保存恢复。
3. 上述通过即执行唯一5614步候选训练及7899正式评估。失败保留原进程日志，不能仅凭loss或CPU检查宣告性能有效。
4. 若超过原生控制但仍未达项目线，只报告局部机制收益；不能替换保护结果。达到Nr要求后尽快推进Sr同结构适配，并以同协议检查Scan。全目标仍为三数据集超过baseline、Scan既有V99保护不退化。

本轮只支持“任务条件读取是否比原生共享读取好”的检验，尚不能支持观测状态、三数据集泛化或多seed稳定性主张。预计训练约5小时（待实测），正式Nr评估约27分钟。Sr当前评估和历史权重均保持独立。
